# SKLAND WIKI DATA SKILL

Public data format skill for SKLand Wiki — wiki JSON, `<sklandDocument>` XML, DocumentModel IR, and `@eihrteam/xml` conversion.

## Installation

### Via vercel `skills`
```bash
npx skills add EIHRTeam/skland-wiki-data-skill
```

### Manual

Download `.zip`/`.tar.gz` file in [Release](https://github.com/EIHRTeam/skland-wiki-data-skill/releases/latest) page
